# Code of Conduct

## In short

Be respectful, be specific, assume good faith, and argue about the code rather than the person. This is a small project maintained around one engine seam; the fastest way to get help is a reproducible report with content-free diagnostics.

## Expected behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences. Many users run this in a production harness, so stability matters more than novelty.
- Give and accept constructive feedback about design, measurements, and tradeoffs.
- Credit others' work. When you build on an idea from another project, say so.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Publishing someone's private information, conversation content, prompts, or session logs without permission.
- Repeatedly derailing issues, or ignoring maintainer decisions after they are explained.
- Encouraging others to bypass the safety or security design of the harness.

## Scope

This applies to issues, pull requests, discussions, and any other project space. Maintainers may edit, remove, or reject content and may block accounts that violate this policy. Serious or repeated violations should be reported privately through the repository's security contact.

## Attribution

This is a minimal project-specific policy, not the Contributor Covenant. It exists so that the rules fit the actual project: a cache-sensitive harness plugin where measurements and reproducibility decide disputes.
